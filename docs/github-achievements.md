# GitHub Achievements

GitHub achievements are earned from real activity on GitHub and appear on the profile when awarded.

## Current profile strategy

- **Quickdraw:** earned by opening and closing a maintenance issue within five minutes.
- **Pull Shark:** earned through merged pull requests authored by this account.
- **YOLO:** may be awarded when an authored pull request is merged without a code review.

Other achievements depend on activity involving other GitHub users, accepted Discussion answers, repository stars, or sponsorship, so they are not manufactured by this repository.
